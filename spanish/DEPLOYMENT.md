# Hola 西语学习网站

静态网页，打开不需要 ChatGPT；中文/西语全站搜索、194小节课程、5000+去重词头、练习和本地学习进度。

此分支由 `spanish-pages.yml` 部署到 GitHub Pages。仓库管理员首次可能需要在 Settings → Pages → Build and deployment 将 Source 设为 GitHub Actions，并允许此分支部署到 github-pages 环境。

学习进度只保存在访问者当前浏览器；复制当前页链接不会包含笔记和答题记录。可用“复制嵌入代码”放入支持 iframe 的网站。

扩展词典并非全部教师审校，来源及许可见 assets/licenses/SOURCES.html。公开产物不含用户教材扫描件或OCR摘录。
