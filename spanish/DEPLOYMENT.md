# 发布网站

网站已发布，公开访问不需要 ChatGPT：

https://385marry-debug.github.io/ui-ux-pro-max-skill/

2026-10-22 GitHub Pages 首次发布成功，记录：https://github.com/385marry-debug/ui-ux-pro-max-skill/actions/runs/39783910005 。网站根目录与 /docs 目录保持一致。

推荐一次性设置：仓库 Settings → Pages → Source 选择 Deploy from a branch → Branch 选择 spanish-learning-site → 文件夹选择 /docs → Save。GitHub 会自动构建网页。

设置入口：https://github.com/385marry-debug/ui-ux-pro-max-skill/settings/pages

GitHub 会在上述设置页显示实际网站地址和发布状态。

后续更新使用同一分支，GitHub Pages 的内置 `pages build and deployment` 会自动发布。修改源码后，运行 `python3 spanish-source/scripts/publish.py` 同步公开文件，再推送到此分支。

源码位于 ../spanish-source/。复制当前页链接可分享课程、词条或搜索；复制嵌入代码可放入允许 iframe 的网站。笔记与学习记录仅存当前浏览器。词库扩展部分未全量人工审校；来源许可见 assets/licenses/SOURCES.html。网站没有附带用户的教材扫描件。

本轮扩展：638动词入口及20组形式规则、16节零基础详解、40单元完整对话与中译、104篇合成音频及232道听力题、24文化课、15场景。详细范围、许可及验证结果见 ../spanish-source/README.md 。
