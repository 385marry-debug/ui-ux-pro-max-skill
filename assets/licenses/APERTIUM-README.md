Derivative noun gender data is also GPL-2.0-or-later. The extraction script is
spanish-source/scripts/build-noun-genders.py in this website's public repository.
Only noun surface forms and morphological m/f/mf tags are extracted; translations
and teaching notes are separately authored. Word-ending guesses are not used.
Multiple gender analyses are retained as ambiguous unless an authored note
explains a common-gender or meaning-dependent use. A morphological dictionary
is not a reviewed dictionary of Spanish-Chinese senses.
